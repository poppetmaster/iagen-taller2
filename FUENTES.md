# Fuentes y continuidad con el Taller 1

El antecedente del proyecto es [iagen-taller1](https://github.com/poppetmaster/iagen-taller1).

Las decisiones técnicas se contrastaron con estas fuentes primarias:

| Fuente | Qué respalda |
|---|---|
| [Ficha de multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small) | Idiomas, licencia, dimensión, prefijos, normalización y límite de tokens |
| [Sentence Transformers](https://www.sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html) | Carga del modelo, revisión y codificación |
| [Chroma: cliente Python](https://docs.trychroma.com/reference/python) | Cliente persistente y alcance local |
| [LangChain con Chroma](https://docs.langchain.com/oss/python/integrations/vectorstores/chroma) | Integración y búsqueda de documentos con puntajes |
| [LangChain con Ollama](https://docs.langchain.com/oss/python/integrations/chat/ollama) | ChatOllama y composición del flujo |
| [Pinecone](https://docs.pinecone.io/guides/get-started/overview) | Servicio administrado y recuperación a escala |
| [Weaviate](https://docs.weaviate.io/deploy) | Alojamiento administrado y por cuenta propia |
| [Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) | Identificación del generador heredado |
